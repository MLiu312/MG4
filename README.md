# MG4
## Devlog
FloatAnimation works by setting _timer to the editable variable _switchSpeed at Start(), then during Update(), _timer counts down while the code checks if _up is True or False, and if True, moves the ball up, and if False, moves the ball down. Once _timer hits zero, it is reset, and _up is flipped.
